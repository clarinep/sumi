# API reference

Sumi provides HTTP endpoints to render card images, check server health, and export execution metrics.

## Endpoints overview

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/render/drop` | Renders a composite card drop image in WebP format. |
| `GET` | `/health` | Returns server health status. |
| `GET` | `/metrics` | Returns server uptime and rendering statistics. |

## Render card drop image

`GET /render/drop`

Combines two card images side by side, stamps print numbers on each card, and returns a single compressed WebP image.

### Query parameters

<ParamField name="left" type="string" required>
  The relative card key for the left card (for example, `genshin/fischl_1`). Do not include the `.webp` file extension.
</ParamField>

<ParamField name="right" type="string" required>
  The relative card key for the right card (for example, `honkai/kafka_1`).
</ParamField>

<ParamField name="left_print" type="integer" optional>
  The print number for the left card. Default: `1`. Values are clamped to the range `1` to `999`.
</ParamField>

<ParamField name="right_print" type="integer" optional>
  The print number for the right card. Default: `1`. Values are clamped to the range `1` to `999`.
</ParamField>

### Example request

```http
GET /render/drop?left=genshin/fischl_1&right=honkai/kafka_1&left_print=42&right_print=102 HTTP/1.1
Host: localhost:8888
```

### HTTP responses

<Tabs>
  <Tab title="200 OK">
    Returned when image rendering succeeds.

    **Headers:** `Content-Type: image/webp`

    **Body:** Binary WebP image payload.
  </Tab>
  <Tab title="404 Not Found">
    Returned when the requested left or right card path is not registered in the card index.

    **Headers:** `Content-Type: application/json`

    ```json
    {
      "error": "card not found: genshin/missing_card"
    }
    ```
  </Tab>
  <Tab title="429 Too Many Requests">
    Returned when the request waits in the task queue longer than the 5-second queue timeout (`QUEUE_TIMEOUT`).

    **Headers:** `Content-Type: application/json`

    ```json
    {
      "error": "render timed out"
    }
    ```
  </Tab>
  <Tab title="500 Internal Error">
    Returned when image decoding fails, canvas memory processing encounters an error, or total request execution exceeds 10 seconds.

    **Headers:** `Content-Type: application/json`

    ```json
    {
      "error": "failed to decode webp for 'assets/cards/invalid.webp'"
    }
    ```
  </Tab>
</Tabs>

## Health check

`GET /health`

Verifies that the HTTP server is running and accepting connections. Use this endpoint for container readiness and liveness probes.

### Response

**Status:** `200 OK`
**Headers:** `Content-Type: text/plain`
**Body:** `OK`

## Metrics

`GET /metrics`

Retrieves operational counters and render metrics.

### Response

**Status:** `200 OK`
**Headers:** `Content-Type: application/json`

```json
{
  "uptime": 3600,
  "successful_renders": 1500,
  "failed_renders": 12,
  "total_image_bytes": 102400000,
  "total_render_duration_ms": 67800
}
```

### Metrics fields

<ResponseField name="uptime" type="integer">
  Elapsed time in seconds since the server started.
</ResponseField>

<ResponseField name="successful_renders" type="integer">
  Total number of successfully completed rendering requests.
</ResponseField>

<ResponseField name="failed_renders" type="integer">
  Total number of failed rendering requests.
</ResponseField>

<ResponseField name="total_image_bytes" type="integer">
  Cumulative byte size of all generated WebP image payloads delivered to clients.
</ResponseField>

<ResponseField name="total_render_duration_ms" type="integer">
  Cumulative duration in milliseconds spent executing image composition and encoding tasks.
</ResponseField>
